What changed

점수를 바꾼 네 가지 수정

표면적인 디자인은 유지하고, 다운로드 크기와 브라우저의 로딩 판단, 실제 실행 오류를 직접 개선했다.

1

대용량 PNG를 WebP로 전환

화면에 표시되는 25장의 핵심 이미지를 WebP로 다시 인코딩했다. 일부는 실제 표시 크기에 맞춰 리사이즈해 불필요한 픽셀 전송도 줄였다.

전송량 감소 → 이미지 다운로드 단축 → LCP 개선
2

첫 화면 이미지는 먼저, 본문 이미지는 나중에

히어로에 fetchpriority="high"를 주고, 화면 아래 이미지는 loading="lazy"로 전환했다. 브라우저가 중요한 이미지를 먼저 받도록 순서를 명확히 했다.

우선순위 명시 → LCP 후보 조기 발견 → 첫 화면 가속
3

이미지 크기를 HTML에 미리 제공

width와 height를 원본 비율에 맞춰 추가했다. 파일을 받기 전에도 브라우저가 공간을 확보할 수 있어 화면 밀림과 비율 오류를 줄였다.

크기 사전 계산 → 레이아웃 안정화 → CLS·권장 사항 개선
4

공통 헤더와 모바일 메뉴 오류 수정

ARIA 역할을 보완하고 미선언 DOM 변수 4개를 명시적으로 연결했다. 잘못 사용하던 hidden도 실제 공통 클래스인 is-hidden으로 통일했다.

실행 오류 제거 → 메뉴 정상 종료 → 접근성과 코드 신뢰성 개선

Code correction

실제 오류를 고친 방식

검사기가 표시한 모든 메시지를 무작정 수정하지 않았다. 외부 CDN과 Tailwind 전용 문법은 분리하고, 실제 실행과 접근성에 영향을 주는 코드만 바꿨다.

헤더 하위 메뉴에 의미 역할 추가

- <div aria-label="전체 하위 메뉴">
+ <div role="group"
       aria-label="전체 하위 메뉴">

모바일 메뉴의 실제 DOM과 상태 클래스 연결

+ const mobileMenu =
    document.getElementById('mobile-menu');

- mobileMenu.classList.add('hidden');
+ mobileMenu.classList.add('is-hidden');
