Figma 연결 지원 안내:

네, Figma 연결이 가능합니다!
현재 Antigravity 환경에는 Figma Dev Mode MCP 도구가 연동되어 있어, Figma 디자인 파일의 정보를 가져오거나 이미지를 다운로드할 수 있는 다음과 같은 도구들이 제공됩니다.

1. get_figma_data (Figma 파일 데이터 조회):
   - Figma 파일 키(fileKey) 및 노드 ID(nodeId)를 입력받아 레이아웃, 텍스트 콘텐츠, 컴포넌트 구조 등의 상세 정보를 JSON 형태로 가져옵니다.
   - 예: figma.com/design/<fileKey>/... 에서 fileKey를 추출하여 사용합니다.

2. download_figma_images (Figma 이미지 다운로드):
   - Figma 시안에 사용된 이미지나 에셋을 다운로드하여 프로젝트 폴더 내에 저장할 수 있습니다.

사용 방법:
- 작업하고자 하는 Figma 시안의 URL이나 디자인 가이드 링크를 공유해 주시면, 해당 데이터를 분석하여 Tailwind CSS 및 프로젝트 테마에 맞추어 코드로 구현해 드릴 수 있습니다.
