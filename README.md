# 풀무원 기업 소개 웹사이트

풀무원의 기업 가치와 바른먹거리, 지구식단 활동을 소개하는 반응형 정적 웹사이트입니다. Figma 시안을 바탕으로 화면을 구현하고, 페이지별 콘텐츠와 상호작용을 점진적으로 보완했습니다.

## 페이지 구성

- 메인: 기업의 핵심 메시지와 주요 콘텐츠를 소개합니다.
- 회사소개: 총괄CEO 인사말, CI, 연혁, 가치체계, 사업소개, 동반성장, 기업지배구조, 투자정보를 제공합니다.
- 바른먹거리: 지속가능 식생활, 지속가능식품, 원칙, 캠페인, 식품안전 및 품질정책을 안내합니다.
- 지구식단: 지구로그와 팝업스토어 콘텐츠를 제공합니다.
- 뉴스룸: ESG·자료실·뉴스·보고서 콘텐츠를 제공합니다.

## 기술 스택

- HTML5
- Tailwind CSS v4 브라우저용 CDN
- Vanilla JavaScript
- GSAP 및 ScrollTrigger·ScrollSmoother·ScrollToPlugin
- Swiper

## 개발 방식

AI 작업 지시와 Figma 시안을 활용해 초기 화면을 구현하고, 저장소 기록을 바탕으로 기능과 디자인을 다듬었습니다.

- 2026-08-10: Figma 시안 3종을 구현하고 디자인 시스템 토큰을 정렬했습니다. (`578a1ee`)
